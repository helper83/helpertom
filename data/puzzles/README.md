# 실사 사진 퍼즐 추가 방법

1. 사진 파일(JPG/WEBP, 가로:세로 4:3, 640×480 권장, 파일당 150KB 이하)을 이 폴더에 넣는다.
2. `manifest.json`에 항목을 추가한다. 예:

```json
[
  { "k": "fuji", "n": "후지산", "file": "fuji.jpg", "tag": "구름 위로 솟은 설산", "pr": 1 },
  { "k": "choco", "n": "빼빼로데이 선물", "file": "choco.jpg", "tag": "달콤한 선물", "a": [11, 11], "sn": "빼빼로데이 · 11/1~11/14" }
]
```

- `k`: 영문·숫자 이름(중복 불가), `n`: 퍼즐 이름, `file`: 사진 파일명
- `pr`: 1이면 ★ 프리미엄 표시, `a`·`sn`: 기념일 한정(월, 일 / 표시 문구)
3. 저장소에 올리면 앱이 자동으로 퍼즐 목록 맨 앞에 추가한다(https 배포 주소에서 동작).

주의: 저작권이 해결된 사진만 사용한다(직접 촬영, CC0·퍼블릭 도메인, 사용 허가를 받은 이미지, 직접 만든 AI 이미지 등).
